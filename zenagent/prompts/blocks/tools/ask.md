Ask the user a structured question and wait for the answer. Use it only when the decision genuinely belongs to the user (an irreversible choice, a preference with no defensible default) or when you are blocked on information only they have; do not ask things you can find out with the other tools. Send 1-5 questions, each with 2-6 options; mark the obvious default as recommended. Without an interactive UI the call returns a note telling you to proceed with the most conservative option instead of blocking.
