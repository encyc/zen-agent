Read a UTF-8 text file. Binary files are refused. Returns whole small files; at most {{default_read_limit}} lines per call by default (hard cap {{max_read_limit}}). A truncated result reports the exact offset for the next page. A successful read marks the file fresh for edit_file and write_file; re-read after changes made outside those tools. Set line_numbers=true to prefix each line with its 1-based number (for inspection only; never write numbered text back).
