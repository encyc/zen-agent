Search saved sessions by regular expression (case-sensitive; (?i) to ignore case). Grouped and paged by session (skip counts sessions): each shows its id, matched count, and excerpts with the message number read_session wants. This project unless all=true. include=conversation (default) is user and assistant text; tools adds tool names and arguments; all adds result bodies. Escalate on an empty level: what a session did usually lives in its tool arguments, and a no-match reply names the level that would match.
