Run a shell command. stdout and stderr are merged; output is truncated to head+tail if very large. Runs non-interactively (pagers/prompts are disabled) and in an optional cwd. Report the exit code yourself when it matters. With async=true the command runs in the background and the wait tool collects its result. Never read files through it (cat/head/tail/sed, or sed/awk as a pager): read_file pages by offset, refuses binaries, and records the read that edit_file requires.
