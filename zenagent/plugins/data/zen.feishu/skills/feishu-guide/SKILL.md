# 飞书连接器使用指南

## 工具命名

插件的 MCP server 名为 `zen.feishu.feishu`，注册后的工具名形如：

    mcp__zen_feishu_feishu__<tool>

用工具列表里的准确名字调用，不要自己拼。

## 常用流程

- **发消息**：确认收件人（群或用户）再发送；凭据只留在环境变量里，正文不要粘贴。
- **查日历**：给出明确时间范围，先查闲忙再建日程。
- **写文档**：先读文档确认标题与段落，改动时说明改哪一节；大段替换前先备份要点。

## 授权排障

- 401/403：App ID/Secret 失效或权限未审批 → 回 setup 检查凭证与应用发布状态。
- 找不到工具：应用未开通对应权限组 → 开放平台补权限后重新发布。
- `npx` 报错：本机没有 Node.js 18+ → 安装后再保存一次插件配置触发重连。
