# 钉钉连接器设置

1. 打开钉钉 [MCP 广场](https://mcp.dingtalk.com)，用管理员账号登录。
2. 为你的组织生成一个 MCP 服务，按需勾选能力（消息、日程、文档、待办）。
3. 复制生成的**整条服务 URL**，粘贴到 zen-agent「插件 → 钉钉」的「MCP 服务 URL」。
4. 保存后插件会自动连接，工具出现在模型可用工具列表里。

## 注意

- 这条 URL 本身就是**长效凭据**，谁拿到它就能以你的身份调用钉钉。不要贴进项目文件、聊天记录或截图。
- zen-agent 只把它保存在本机 `~/.zenagent/settings.json`（权限 0600），日志与界面里只会显示掩码。
- 连接失败先看错误里的状态码：401/403 说明 URL 已失效，回广场重新生成；超时检查本机网络能否访问 `mcp.dingtalk.com`。
