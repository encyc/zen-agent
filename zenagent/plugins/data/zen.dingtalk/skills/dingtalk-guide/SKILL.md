# 钉钉连接器使用指南

## 工具命名

插件的 MCP server 名为 `zen.dingtalk.dingtalk`，注册后的工具名形如：

    mcp__zen_dingtalk_dingtalk__<tool>

server 名里的点与连字符会被替换成下划线。用工具列表里的准确名字调用，不要自己拼。

## 常用流程

- **发消息**：先确认收件人（群名或用户），再调用发送工具；正文里不要粘贴凭据。
- **查日程**：给出明确的时间范围（今天、本周、某天），避免拉全量日程。
- **读写文档**：先取文档元信息确认标题，再读正文；改动前说明要改哪一段。

## 授权排障

- 返回 401/403：MCP URL 失效或权限被收回 → 回「插件 → 钉钉」的 setup 重新生成并粘贴 URL。
- 返回工具不存在：组织侧未勾选对应能力 → 回 MCP 广场重新授权。
- 连接超时：检查网络与 `mcp.dingtalk.com` 可达性，重试前不要重复粘贴 URL。
