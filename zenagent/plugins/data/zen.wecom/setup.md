# 企业微信连接器设置

> **文档类授权 7 天到期。** 连接突然失败（401/403）时，第一件事是回管理页重新授权，再复制新的 MCP 服务 URL。

1. 打开企业微信管理后台，进入「智能机器人」，创建一个机器人。
2. 按需逐项授权能力（消息、文档、日程、会议）。
3. 用管理员企业微信扫码确认，复制页面给出的**整条 MCP 服务 URL**。
4. 把 URL 粘贴到 zen-agent「插件 → 企业微信」并保存。

## 注意

- 这条 URL 本身就是**长效凭据**，不要贴进项目文件或聊天记录；zen-agent 只把它保存在本机 `~/.zenagent/settings.json`（0600）。
- 文档类权限有效期 7 天，到期后工具会返回 401，重新授权即可，不需要重装插件。
