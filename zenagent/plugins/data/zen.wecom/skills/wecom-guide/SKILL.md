# 企业微信连接器使用指南

## 工具命名

插件的 MCP server 名为 `zen.wecom.wecom`，注册后的工具名形如：

    mcp__zen_wecom_wecom__<tool>

用工具列表里的准确名字调用，不要自己拼。

## 常用流程

- **发消息**：确认是群聊还是单聊、收件人是谁，再发送。
- **查文档**：先列出可用文档，再按标题读取；不要一次拉全量。
- **排会议**：先查参会人闲忙，再建会议。

## 授权排障

- 401/403：**文档类授权 7 天到期**是最常见原因 → 回管理页重新授权并更新 MCP 服务 URL。
- 部分工具消失：对应能力被收回 → 在机器人授权页逐项补回。
- 连接超时：确认本机能访问 `work.weixin.qq.com`。
