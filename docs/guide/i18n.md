# 界面语言（i18n）

ZenAgent 的界面（TUI + REPL + 命令输出）默认英文，可选简体中文；两套文案由同一个纯 stdlib 的
catalog 提供，**模型面向的提示词、工具描述、skill 正文不翻译**。这篇讲怎么用、怎么加语言、以及
哪些东西故意不翻。

## 怎么切

优先级从高到低：`--lang` flag > `~/.zenagent/settings.json` 的 `prefs.language` >
`ZENAGENT_LANG` 环境变量 > `LANG`/`LC_ALL`/`LC_MESSAGES`（`zh*` → 中文，其余 → 英文）。

| 入口 | 说明 |
| --- | --- |
| `--lang auto\|en\|zh` | 启动时指定，只影响本次进程 |
| `/lang [auto\|en\|zh]` | TUI 与 REPL 都有；不带参数时 TUI 打开选择器、REPL 打印用法 |
| `/settings → Language…` | TUI 设置面板；选中即持久化并**即时**重建界面 |
| `prefs.language` | 应用写入的持久偏好；`auto` 表示跟系统 locale |
| `LANGUAGE_CHOICES` | 代码里的规范词表：`("auto", "en", "zh")` |

`auto` 的判定顺序：`ZENAGENT_LANG` → `LANG` → `LC_ALL` → `LC_MESSAGES`，取第一个 `zh*`/`en*`
前缀；都没有则英文。`zh-CN`、`zh_CN.UTF-8`、`zh-Hans` 都归一成 `zh`。

```bash
zen --lang zh                     # 本次中文
zen --no-tui --lang zh            # REPL 中文
# TUI 里： /lang zh  或  /settings → Language…
```

切换是**即时**的：`ZenAgentApp.set_language()` 会 `set_locale`、重建命令 registry（描述在构建时
翻译）、刷新侧栏标题，并重绘 Rich 文本；正在跑的输出不会被中止。REPL 的 `/lang` 对后续输出生效。

## 翻译范围

**翻译**：TUI 全部界面文案（状态带、侧栏、工作条、todo HUD、工具卡标签、输入框提示、选择器、
对话框、浮层、通知、帮助）、REPL 命令表与输出、slash 命令描述与参数说明、审批/ask 对话框、
会话/错误提示、tool card 的运行时状态标签。补全条目里的类型标签（命令/模板/扩展/技能）也翻。

**不翻（有意为之）**：

| 内容 | 原因 |
| --- | --- |
| `zenagent/prompts/**`、工具描述/schema、skill 正文 | 模型面向契约，翻译会改变模型行为与评测基线 |
| 命令名、flag、tool 名、keybinding 名、模型 id、CSS class | 标识符；中文下 `/` 补全仍显示英文命令名 |
| 代码块、路径、`$`/`≈`/`%` 等符号 | 语义稳定，翻反而误导 |
| `--help` argparse 文本、`doctor/usage/export/sessions` 子命令输出 | 开发者/机器面向，属于第二刀 |
| 配置/扩展/skill 加载的 warning 原文 | 来自各模块的英文诊断，属于第二刀 |
| `docs/` | 文档保持中文，与 UI 语言无关 |

## catalog 怎么组织

```
zenagent/i18n/
├── __init__.py     # t() / tn() / set_locale() / resolve_language()
├── en.py           # 权威文案（FAQ：默认 locale 是 en，现有测试即回归闸门）
└── zh.py           # 与 en.py key 一一对应
```

- 扁平 `dict[str, str]`，key 用点分命名空间：

  | 前缀 | 归属 |
  | --- | --- |
  | `tui.*` | Textual 部件与屏幕（`tui.sidebar.*`、`tui.dialog.*`、`tui.status.*`、`tui.tool.*` …） |
  | `cmd.*.description` | slash 命令描述（registry 构建期解析） |
  | `cmdmsg.*` | 命令输出（REPL/TUI 共用） |
  | `repl.*` | REPL 专属输出与命令表 |
  | `arg.*` | slash 参数值说明（picker/completion 共用） |
  | `type.*` | 补全类型标签 |
  | `session.*` / `runtime.*` / `perm.*` / `notice.*` | 共享层错误/通知 |
  | `skill.*` | skill 命令的用户可见错误 |
  | `mode.describe` | `/mode` 一行摘要 |

- 占位符用 `str.format` 的**具名**字段（`{used}`、`{window}`），翻译可以重排顺序；`t()` 的
  key 参数叫 `message_key`，所以 `{key}`/`{n}` 这类占位符不会和参数名冲突。
- 复数：`tn("key", n)` 取 `key.one` / `key.other`；中文两分支写同一句。
- 回退链：当前 locale → en → key 本身（运行时绝不抛异常）；en/zh 的 key 集与占位符由
  `tests/test_i18n.py` 强制对齐，`tn` 的 `.one/.other` 必须成对。

## 加一门语言

1. 复制 `zenagent/i18n/en.py` → `xx.py`，逐条翻译（值必须保留所有占位符）。
2. `zenagent/i18n/__init__.py`：`_CATALOGS` 加 `"xx": _XX`，`LANGUAGE_CHOICES` 加 `"xx"`，
   在 `_normalize()` 里加前缀判定（如 `startswith("ja")`）。
3. `tests/test_i18n.py` 的 parity 测试会自动覆盖新 catalog；再在 `tests/test_i18n_tui.py` /
   `tests/test_i18n_app.py` 补几条该语言的冒烟（标题、命令表、关键对话框）。
4. 文档：`docs/guide/i18n.md` 的表格加一行；不需要改前端代码 —— 所有文案都走 `t()`。

CJK/宽字符：TUI 的裁剪用 `zenagent/cli/tui/textutil.py`（`clip_cells` / `pad_cells`，
基于 `rich.cells.cell_len`），不要用 `len()` 判断行宽；`tests/test_i18n_tui.py` 有宽度不变量测试。

## 测试与开发

- `tests/test_i18n.py`：key/占位符对齐、复数成对、回退链、locale 规范化与优先级、`set_locale`。
- `tests/test_i18n_tui.py`：TUI 中文冒烟（侧栏分区、设置菜单、审批、job 日志、上下文浮层、
  todo 浮层、输入框、工具卡、命令提示前缀）与 CJK 宽度。
- `tests/test_i18n_app.py`：slash 参数/命令描述/通知、REPL 命令表与 `/help`、`/lang` 切换。
- `tests/conftest.py` 有 autouse fixture：每个测试开始和结束都把 locale 重置为 `en`，避免全局状态串味。
- 新增 UI 文案时：先加 key 到 en.py/zh.py（en 值保持逐字不变），再在代码里 `t(…)`；直接跑
  `bash scripts/check.sh` 就能拿到 parity 与回归双重校验。

## 术语表（en ↔ zh）

| en | zh | 备注 |
| --- | --- | --- |
| session | 会话 | |
| mode (`plan`/`ask`/`full`) | 模式 | 模式值本身不翻 |
| thinking / reasoning | 思考 / 推理 | 等级值 `off|low|…` 不翻 |
| skill | 技能（命令里保留 `skill:` 前缀） | `/skill:<name>` 是契约 |
| template | 模板 | |
| extension | 扩展 | |
| context (window) | 上下文（窗口） | `ctx` 缩写译作 `上下文` |
| compact / compaction | 压缩 | |
| subagent / task | 子代理 / 子任务 | |
| background job | 后台任务 | `job id` 保留 |
| approve / allow | 批准 / 允许 | |
| retry / undo | 重跑 / 撤回 | |
| theme / appearance | 主题 / 外观 | `dark`/`light`/`auto` 值不翻 |

## 源码对照

- catalog 与运行时：`zenagent/i18n/__init__.py`（`t`、`tn`、`set_locale`、`resolve_language`）、
  `zenagent/i18n/en.py`、`zenagent/i18n/zh.py`

  `zenagent/cli/repl.py::repl`（启动 `set_locale` 与本地 `set_language`）
- 命令描述与参数：`zenagent/app/commands.py::_command`、`zenagent/app/slash_args.py`、
  `zenagent/cli/completion.py::slash_commands`
- 宽度工具：`zenagent/cli/tui/textutil.py`
- 测试：`tests/test_i18n.py`、`tests/test_i18n_tui.py`、`tests/test_i18n_app.py`
