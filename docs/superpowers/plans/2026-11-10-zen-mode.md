# Zen Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每项目一个 Router 交互会话（Zen 模式），Router 用工具异步派工/收报告，管理项目下所有 worker session。

**Architecture:** 进程内 ZenFleet 挂在 RuntimeSlot；worker = 独立 `prepare()` 的 Runtime 复用既有 session 文件；报告经 `chat.steer` 注入 Router。RPC 新 kind `zen_fleet`（enable/disable/state/transcript）+ 服务端主动 roster 帧；前端 sidebar 切换按钮 + worker 名册 + 只读抽屉。

**Tech Stack:** Python 3.11 asyncio（kernel + app 层）、JSONL stdio RPC、React 18 + Zustand 5 + node:test。

**Spec:** `docs/superpowers/specs/2026-11-10-zen-mode-design.md`

## Global Constraints

- 分层铁律：`app/` 不 import `zenagent.cli`；`agent/` kernel 不知道 CLI（`tests/test_layering.py`）。
- 源文件 ≤ 800 行（`scripts/check_architecture.py`）；新文件小而专注。
- 零新第三方依赖（kernel 只有 httpx）。
- 命名空间：权限模式值 `zen` 已被占用（plan/ask/zen）；wire kind 用 `zen_fleet`。
- 契约三方同步：Python dispatcher ↔ `desktop/src/rpc/types.ts REQUEST_KINDS` ↔ `tests/test_rpc_contract.py`。
- `PROTOCOL_VERSION` 2 → 3（codec.py、types.ts、契约测试三处同步）。
- 验收门禁：`scripts/check.sh`（uv sync --extra cli --dev + ruff + architecture budget + pytest）与 `desktop: pnpm test && pnpm build`。
- 前端字符串 zh/en 双字典齐平（`desktop/tests/locale.test.ts`）。

## Review Focus

1. **busy slot 上切换 Zen**：正在流式输出时 enable/disable 必须拒绝而非打断 —— 测试钉在 Task 4（`zen_busy` refusal）。
2. **Router session 误派工**：`fleet_dispatch` 指向 router 自身必须拒绝 —— Task 2。
3. **并发上限**：超过 `max_concurrent` 的派工必须排队而非并行轰炸 —— Task 2。
4. **slot 驱逐/关闭时 worker 泄漏**：fleet 持有在跑 worker 时 slot 必须 pinned，close 必须 abort —— Task 4。
5. **旧 kernel + 新 GUI**：`zen_fleet` 发到 v2 server 会报 unknown kind —— PROTOCOL_VERSION 握手兜底，Task 4 契约测试。

### Task 2: ZenFleet 核心

**Files:**
- Create: `zenagent/app/zen/prompts.py`, `zenagent/app/zen/fleet.py`
- Test: `tests/test_zen_fleet.py`

**Interfaces:**
- Consumes: Task 1 roster 函数；`zenagent.app.bootstrap.prepare`（模块级 import，测试 monkeypatch）；`records.open_session` + `unique_session_path`。
- Produces:
  - `prompts.py`: `ROUTER_PROMPT_NOTE: str`（Router 纪律：只分派/协调/汇报，不亲自实现；结果异步到达，禁止 sleep/轮询等待；状态词表）；`worker_prompt(focus: str, task: str) -> str`。
  - `fleet.py`: `WorkerStatus = Literal["idle","queued","working","waiting","blocked","failed"]`；
    `RosterRow` TypedDict(`path: str, title: str, focus: str, role: str, status: WorkerStatus, last_report: str`)；
    `ZenFleet(runtime, chat, root: Path, *, max_concurrent: int = 3, on_change: Callable[[], None] | None = None)`：
    - `async dispatch(session_path: str, task: str) -> WorkerStatus`（worker 正在 working → `ValueError`；指向 router session → `ValueError`；超并发 → 排队返回 `"queued"`，否则 `"working"`）
    - `async stop(session_path: str) -> bool`
    - `focus(session_path: str, focus: str) -> None`（写 roster + on_change）
    - `spawn(focus: str) -> str`（`unique_session_path` 新建 lazy session，登记 worker + focus，返回 path）
    - `roster() -> list[RosterRow]`（扫描 sessions_dir：titles 侧车标题 + roster focus/role + 句柄状态/报告；router 行 status="router"）
    - `has_active() -> bool`（working 或 queued 存在）
    - `async close() -> None`（abort 全部在跑，状态置 blocked）
  - worker 回合结束：报告 = 最后一条 assistant 文本 ≤800 字符，状态 waiting，`chat.steer(f"[zen:worker {title}] {report}")` 注入并 `on_change()`。
