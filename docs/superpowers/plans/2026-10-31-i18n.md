# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让界面支持 `auto|en|zh`（`/lang`、`--lang`、settings 面板可切、持久化），文案走一套纯 stdlib 的 catalog；默认 en 下所有现有行为/测试文本不变；中文下 TUI/REPL/命令描述/审批通知全部中文且不破坏行宽。

**Architecture:** 新增叶子模块 `zenagent/i18n/`（`t()` / `tn()` / `set_locale()` / locale 解析，en.py + zh.py 两张扁平 catalog）。所有界面文案改为 `t("命名空间.区域.key")`；`app/commands.py` 的命令描述改为按 catalog key 在 registry 构建时解析（这样切换语言后重建 registry 即生效）。TUI 的 `set_language` 复用主题的 `_repaint_rich()` 重建路径，并重建命令 registry。CJK 宽度用 `rich.cells.cell_len` 的 `clip_cells` 收口。

**Tech Stack:** Python 3.11+、stdlib only（`str.format` 占位符）、rich `cell_len`、pytest + Textual `run_test()`。

**Spec:** `docs/superpowers/specs/2026-10-31-i18n-theme-design.md` §5.5–5.7（theme 部分已实现，见 `docs/superpowers/plans/2026-10-31-theme-appearance.md`）

## Global Constraints

- 无新依赖；`zenagent/i18n/` 不 import textual/rich，只 stdlib。
- **默认 locale = en，en catalog 的每条文案必须与当前字面量逐字一致**（现有测试断言不变）。
- 不翻：`zenagent/prompts/**`、工具描述/schema、skill 正文、slash 命令名、flag 名、tool 名、keybinding 名、CSS class/id、模型 id、路径、代码块。
- 第一刀不含：`--help` argparse 文本、`doctor/usage/export/sessions` 子命令输出、RPC/telemetry/crash。
- 每个 task 结束跑该 task 测试 + `bash scripts/check.sh`。
- 中文文案宽度：TUI 展示文本一律用 `cell_len` 计算/裁剪，禁止用 `len()` 判断行宽（`tests/test_i18n_tui.py` 会抽查）。

## Review Focus

1. 未知/缺失 catalog key：`t()` 必须回退 en → key，绝不抛异常；测试 strict 模式只用于测试。
2. 占位符：en/zh 的 `{}` 字段集必须一致（翻译重排顺序可以，丢字段不行）。
3. 复数：英文 `1 items` 不能出现；`tn()` 走 `.one`/`.other`，zh 两分支同文案。
4. 中文宽度：侧栏/状态带/浮层在 zh 下 cell 宽不超限（`_clip` 已是 char-based 的地方必须换成 cell-based）。
5. 语言切换不打断运行、丢 transcript、影响命令名：切换后 `/` 补全仍是英文命令名 + 中文描述。

### Task 1: i18n 核心模块

**Files:**
- Create: `zenagent/i18n/__init__.py`、`zenagent/i18n/en.py`、`zenagent/i18n/zh.py`
- Test: `tests/test_i18n.py`

**Interfaces:**
- `LANGUAGE_CHOICES: tuple[str, ...] = ("auto", "en", "zh")`
- `set_locale(spec: str | None = None, *, environ: Mapping[str, str] | None = None) -> str`（返回生效 code；`auto`/None → 环境探测）
- `active_locale() -> str`
- `available() -> tuple[str, ...]`（`("en", "zh")`）
- `t(key: str, **fmt) -> str`（当前 locale → en → key）
- `tn(key: str, n: int, **fmt) -> str`（`.one` / `.other`）
- `resolve_language(flag: str | None = None, *, pref: str | None = None, environ=None, warnings: list[str] | None = None) -> str`（优先级 flag > pref > `ZENAGENT_LANG` > `LANG`/`LC_ALL`/`LC_MESSAGES` 的 zh 前缀 > en；非法值 warn + auto）
- 参数先用测试里的一小批 key（`test.*`）验证机制；真实文案在 Task 2/3/4 填充。

```python
# tests/test_i18n.py
import pytest

from zenagent import i18n


def test_catalogs_are_key_and_placeholder_identical():
    from string import Formatter

    en, zh = i18n._catalogs()  # {"en": {...}, "zh": {...}}
    assert set(en) == set(zh)
    for key, english in en.items():
        fields = {name for _, name, _, _ in Formatter().parse(english) if name}
        fields_zh = {name for _, name, _, _ in Formatter().parse(zh[key]) if name}
        assert fields == fields_zh, key
    for key in en:
        assert not key.endswith((".one", ".other")) or key[: -len(".one")] in en or True


def test_plural_pairs_are_complete():
    en = i18n._catalogs()["en"]
    ones = {key[: -len(".one")] for key in en if key.endswith(".one")}
    others = {key[: -len(".other")] for key in en if key.endswith(".other")}
    assert ones == others


def test_default_locale_is_english(monkeypatch):
    monkeypatch.setattr(i18n, "_catalogs", lambda: {"en": {"a": "A"}, "zh": {"a": "甲"}})
    assert i18n.set_locale("en") == "en"
    assert i18n.t("a") == "A"


def test_t_falls_back_to_english_then_key(monkeypatch):
    monkeypatch.setattr(
        i18n, "_catalogs", lambda: {"en": {"a": "A", "only_en": "E"}, "zh": {"a": "甲"}}
    )
    i18n.set_locale("zh")
    assert i18n.t("a") == "甲"
    assert i18n.t("only_en") == "E"
    assert i18n.t("missing.key") == "missing.key"


def test_placeholders_are_formatted():
    i18n.set_locale("en")
    assert i18n.t("test.greeting", name="zen") == "hello zen"


def test_plural_picks_one_or_other(monkeypatch):
    monkeypatch.setattr(
        i18n,
        "_catalogs",
        lambda: {
            "en": {"x.one": "{n} item", "x.other": "{n} items"},
            "zh": {"x.one": "{n} 项", "x.other": "{n} 项"},
        },
    )
    i18n.set_locale("en")
    assert i18n.tn("x", 1, n=1) == "1 item"
    assert i18n.tn("x", 3, n=3) == "3 items"
    i18n.set_locale("zh")
    assert i18n.tn("x", 3, n=3) == "3 项"


@pytest.mark.parametrize(
    ("spec", "expected"),
    [
        ("zh", "zh"),
        ("zh-CN", "zh"),
        ("zh_cn.UTF-8", "zh"),
        ("zh-Hans", "zh"),
        ("en", "en"),
        ("en_US.UTF-8", "en"),
        ("auto", None),
        ("nonsense", None),
    ],
)
def test_resolve_language_normalizes_codes(spec, expected):
    if expected is None:
        return  # auto/unknown resolves via the environment; covered below
    assert i18n.resolve_language(spec, environ={}) == expected


def test_resolve_language_priority_and_environment():
    assert i18n.resolve_language("zh", pref="en", environ={}) == "zh"
    assert i18n.resolve_language(None, pref="zh", environ={}) == "zh"
    assert i18n.resolve_language(None, pref=None, environ={"ZENAGENT_LANG": "zh"}) == "zh"
    assert i18n.resolve_language(None, pref=None, environ={"LANG": "zh_CN.UTF-8"}) == "zh"
    assert i18n.resolve_language(None, pref=None, environ={"LANG": "en_US.UTF-8"}) == "en"
    assert i18n.resolve_language(None, pref=None, environ={}) == "en"


def test_unknown_language_warns_and_falls_back():
    warnings: list[str] = []
    assert i18n.resolve_language("nonsense", environ={}, warnings=warnings) == "en"
    assert warnings and "nonsense" in warnings[0]
```
