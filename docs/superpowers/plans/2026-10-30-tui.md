# ZenAgent TUI 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 ZenAgent 上新增一个 Textual 全屏 TUI（底部状态栏、可折叠侧边栏、模型/会话管理、队列与中断），同时把 REPL/TUI/RPC 共用的应用层（`zenagent.app`）抽出来，作为公开嵌入 API。

**Architecture:** 三层：内核（已有）→ `zenagent.app`（Runtime/ChatController/ModelManager/SessionManager/CommandRegistry/PermissionBroker，禁止依赖任何 UI 库）→ 前端（TUI、REPL、RPC）。TUI 只负责渲染与键盘输入，所有状态经 app 层快照 + `on_change` 获取。

**Tech Stack:** Python 3.11+、Textual >=8.2,<9、rich（已有）、pytest、pytest-asyncio。

**Spec:** `docs/superpowers/specs/2026-10-30-tui-design.md`

## Global Constraints

- `requires-python >= "3.11"`；CI 矩阵 3.11 + 3.14。
- Textual 只允许出现在 `[project.optional-dependencies].cli`，pin `textual>=8.2,<9`。
- `zenagent/app/**` 不得 import `argparse`、`textual`、`prompt_toolkit`、`rich`。
- 现有 565 个测试必须全绿；`zen -p`、`--json`、`zen rpc` 的 stdout 协议不得改变。
- TUI 只在 TTY 且未指定 `--no-tui` 时启动；非 TTY 自动回落到行式 REPL 并打印一行说明。
- 不做鼠标、不做动画（仅等待 spinner）、不做 3D。
- 会话删除移到 `~/.zenagent/sessions/.trash/`，不 unlink。
- 每个任务结束时 `bash scripts/check.sh` 必须绿。

## Review Focus

按「用户最可能撞上、猜错就难受」排序，每条的测试放在负责该代码的任务里：

1. **非 TTY 启动 `zen`**：必须回落到 REPL 并正常工作，而不是崩在 Textual 初始化。（T9）
2. **切到没配 key 的模型**：选择器置灰并说明原因，不能切完下一轮才报错。（T5）
3. **运行中切换会话**：先 abort 再切换，UI 不崩、不丢队列。（T6/T13）
4. **80 列窄终端**：侧边栏默认隐藏，输入区与状态栏仍可用。（T13）
5. **工具执行中按 Ctrl+C**：run 变 aborted，bash 进程组被杀，TUI 不退出。（T11）

```python
# tests/test_app_chat.py
import asyncio
from zenagent.app.chat import ChatController
from zenagent.app.views import ToolCallView


async def fake_runtime(tmp_path, monkeypatch, gate: asyncio.Event):
    from zenagent.app.runtime import Runtime, RuntimeOptions
    monkeypatch.setenv("DEEPSEEK_API_KEY", "test-key")
    monkeypatch.setattr("zenagent.app.runtime.sessions_dir", lambda: tmp_path / "sessions")

    async def stream(model, messages, tools, options):
        from zenagent.events import AssistantEvent
        from zenagent.types import AssistantMessage, TextContent, Usage
        partial = AssistantMessage(content=[TextContent(text="")], provider="p", model="m",
                                   usage=Usage(), stop_reason="pending", timestamp=0)
        yield AssistantEvent(type="start", partial=partial)
        await gate.wait()
        partial.content[0].text = "done"
        partial.stop_reason = "stop"
        yield AssistantEvent(type="text_delta", partial=partial, content_index=0, delta="done")
        yield AssistantEvent(type="done", partial=partial, reason="stop")

    return await Runtime.bootstrap(RuntimeOptions(mcp=False, skills=False, templates=False), stream_fn=stream)


async def test_submit_streams_and_second_submit_queues(tmp_path, monkeypatch):
    gate = asyncio.Event()
    runtime = await fake_runtime(tmp_path, monkeypatch, gate)
    changes = []
    chat = ChatController(runtime, on_change=lambda: changes.append(1))
    try:
        task = asyncio.create_task(chat.submit("hi"))
        await asyncio.sleep(0.05)
        assert chat.status.running is True
        await chat.submit("follow up")       # running → queued
        assert chat.status.follow_ups == 1
        gate.set()
        await task
        await asyncio.sleep(0.05)            # queued message auto-sent
        assert changes and chat.status.follow_ups == 0
        assert chat.transcript[0].text == "hi"
    finally:
        await runtime.close()
```
