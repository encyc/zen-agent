**目标：** 把 pyagent 从「引擎能跑」推到「日常敢用」：有 CI 把关、有成本与回合护栏、能读项目约定、上下文会自动压缩、会话可列可叉可撤回、所有交互有反馈（diff/状态行/补全）、危险命令不因 `--yes` 裸奔、图片能进得去。

## Global Constraints（新增部分，其余沿用原计划）

- 内核（`types/events/providers/agent/tools`）仍然只依赖 `httpx`；S1 不新增运行时依赖（`rich`/`prompt_toolkit` 仍在 cli extra）。
- 所有新行为必须有离线单测；CI 只跑离线套件，不调用真实 API。
- 旧会话文件不可变：fork / undo / import 一律写**新文件**，不原地改写。
- 破坏性限制默认开启：`--yes` 不解除危险命令拦截，需额外的 `--allow-dangerous`。
- 每个任务结束跑 `bash scripts/check.sh`（T1 建立）与 `git commit`。

## Review Focus（本计划的高风险点，已钉进对应任务）

1. **护栏不得误伤正常长任务**：默认轮次上限保持 100；`--max-cost` 只在显式设置时生效，且不改变 `stop_reason` 语义（只记 `termination`）。
2. **自动压缩不得在 run 中途触发**：只在 `agent_end` 之后、空闲时执行；失败要静默回退（保留原 transcript），并让手工 `/compact` 仍可用。
3. **项目指令注入有界**：`AGENTS.md` 之类最多 32KB、固定位置（system prompt 尾部）、`--no-context-files` 可关；不得因注入内容破坏请求结构。
4. **会话操作不破坏旧文件**：fork/undo/import 写新 JSONL，旧文件字节不变（T5/T6 测试显式断言）。
5. **危险命令只拦明确模式**：大小写/空白归一后匹配有限模式集；正常 `rm -rf ./build` 必须放行。→ T2。
6. **图片在发请求前失败**：非 vision 模型、非图片 MIME、>5MB 都在本地报错退出，不浪费 token。→ T12。
